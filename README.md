# Smart Plant Guardian

Smart Plant Guardian is a smart gardening and plant care project designed to help users monitor and maintain healthy plants using connected sensors and automated insights.

## Overview

This project aims to provide a simple, practical solution for plant care by tracking environmental conditions such as:

- Soil moisture
- Temperature
- Light exposure
- Humidity
- Plant health status

The goal is to help users detect when a plant needs water, light adjustment, or other care before it becomes unhealthy.

## Features

- Real-time plant monitoring
- Sensor-based environmental tracking
- Watering reminders and alerts
- Smart plant health insights
- Easy-to-use dashboard or interface
- Scalable design for future device integration
